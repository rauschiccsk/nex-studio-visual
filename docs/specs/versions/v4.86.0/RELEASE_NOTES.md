# v4.86.0

**Plán úloh ukazuje, koľko bude agent naozaj pracovať.** Doteraz plán sčítal odhady agenta v hodinách práce
človeka — pri NEX Manager 1.4.0 „~54 h“, hoci agent úlohy urobil asi za hodinu. Teraz trvanie odhaduje kokpit sám
z času, ktorý agent naozaj pracoval na úlohách predošlých stavieb toho istého projektu, s nameraným rozpätím
(napríklad „asi 1 h 20 min ± 30 %“). Počas stavby sa odhad s každou hotovou úlohou spresňuje a Plán úloh ukáže aj
„zostáva asi …“. Odhady v hodinách človeka sa zrušili úplne.
