# v4.181.0

**Snímka obrazovky v rozhovore so Staviteľom presne ako v Nápadoch.** Snímku vložíš do poľa cez Ctrl+V alebo ju tam
pretiahneš: nad poľom sa ukáže ako malý obrázok (krížikom ju odoberieš) a odíde spolu so správou — pri Poslať aj pri
Uprav. V rozhovore ju potom vidno pri tvojej správe ako malý obrázok, kliknutím sa zväčší. Staviteľ ju dostane spolu
so správou a otvorí si ju len na čítanie.

Snímky sa už **neukladajú do projektu**: ležia v dátach kokpitu pri rozhovore verzie a keď je verzia dokončená alebo
zrušená (či projekt zmazaný), kokpit ich zmaže sám. Vo verzii 4.180.0 sa vložená snímka ukladala ako súbor do
priečinka private/ projektu — to je preč. Tlačidlo „Priložiť súbor“ ostáva na súbory, ktoré má projekt naozaj mať.
Súbor, ktorý nie je obrázok, pole neprijme ako snímku a povie, že patrí do „Priložiť súbor“.
