doteraz si každá tabuľka rozdelila stĺpce podľa svojho obsahu. V riadku majú verzia, stav a tlačidlo „Otvoriť“ pevné
miesta a dôvod, prečo inštalácia neodpovedá, je na druhom riadku pod nimi.
