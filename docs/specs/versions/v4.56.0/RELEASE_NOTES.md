# v4.56.0

**Kokpit sa začína učiť projekty s webom a administráciou.** Voľba „Web“ na obrazovke Nový projekt je zatiaľ
zašednutá a pod ňou je vysvetlenie — doteraz sa dala vybrať, ale vytvorila projekt len s jedným frontendom. Sprístupní
sa, keď kokpit bude vedieť web a administráciu postaviť, ukázať vo Vizuáli, overiť aj nasadiť. Odteraz si kokpit
pamätá frontendy každého projektu na jednom mieste: pri Web projekte administráciu (prihlásenie menom a heslom) aj web
(prihlásenie e-mailom a heslom), každý s vlastným portom.
