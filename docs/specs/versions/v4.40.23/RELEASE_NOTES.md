# v4.40.23

V prehľade stavby je nad rozhovorom nová veta o poslednom zostavení: či prešlo, zlyhalo, alebo sa to
zatiaľ nedá povedať. Pri zlyhaní je napísané, ktorý postup padol a ktorý beh — nielen číslo.

Doteraz sa o červenom zostavení dalo dozvedieť až na bráne pred vydaním, čiže vtedy, keď je verzia
hotová a treba ju prerábať.
