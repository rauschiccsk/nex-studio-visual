# v4.132.0

**Riadiace centrum pri nespustenej verzii ponúkne jej štart.** Keď verzia ešte nebeží, Riadiace centrum povie
„Verzia ešte nebeží“ a ukáže tlačidlo „Spustiť tvorbu špecifikácie“ — to isté ako na stránke verzie. Doteraz tam bolo
prázdne okno a štart bol len na stránke verzie. Pole na správy je dovtedy zamknuté s vetou prečo: prvá správa už verziu
potichu nespustí v režime rozhovoru bez päťfázového postupu, ako sa mohlo stať doteraz.
