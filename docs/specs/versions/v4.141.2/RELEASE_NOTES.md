# v4.141.2

**Medzi rovnako podobnými tiketmi je novší vyššie.** Keď na hľadanie sedí viac tiketov rovnako (napríklad krátka
otázka „meno v šablóne projektov“ zhodou dvoch slov stretla 13 tiketov kokpitu), kokpit ich doteraz radil tak, ako
ich vrátil Plane — od najstaršieho — a najnovší tiket mohol vypadnúť z piatich zobrazených. Teraz ide pri rovnakej
zhode novší tiket skôr, v náhľade pod tlačidlom „Založiť tiket“ aj u Poradcu; nedávny tiket je pravdepodobnejšie
ten, ktorý hľadáš.
