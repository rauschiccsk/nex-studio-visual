# v4.178.0

**Čo sa nastaví pri založení projektu, je záväzné.** Typ projektu, prihlásenie a frontendy sa počas tvorby nemenia.
Stránka projektu už neponúka „Prepnúť na Web“ — namiesto rámika „Projekt s webom“, ktorý vyzeral ako nastavenie
projektu, ukazuje „Frontendy projektu“: tie, ktoré projekt naozaj má.

**Pridať webový frontend — len admin, pred PROD, s dôvodom.** Jediná výnimka z pravidla: účet admin môže projektu
pridať webový frontend (web s prihlásením e-mailom), kým projekt nebol nasadený do PROD, a musí napísať dôvod, ktorý sa
zapíše spolu s tým, kto to urobil. Projekt na šablóne aplikácií ho dostane, keď šablóna bude vedieť webový frontend.
