# v4.102.1

**Aplikácia na šablóne ukazuje v Aktualizáciách správny dátum pri každej verzii, aj pri starších.** Kokpit pri vydaní
zapíše deň, keď bola každá verzia projektu prvý raz overená alebo označená ako hotová, a dátum odhadnutý agentom
opraví. Verzia, o ktorej kokpit záznam nemá, si svoj dátum ponechá.
