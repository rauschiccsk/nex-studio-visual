# v4.101.0

**Projekt postavený bez šablóny môžeš previesť na šablónu aplikácie.** Pri zakladaní novej verzie takého projektu ti
kokpit ponúkne „Previesť na NSV štandard“. Kokpit pridá šablónu jedným zápisom a obrazovky projektu nechá; do
jednotného rámu ich presunie agent v tej verzii, ktorú zakladáš — Príprava to dostane ako riadnu položku a kokpit pred
Overením skontroluje, že je rám celý.

Kým má projekt rozpracovanú verziu alebo už nasadenú inštaláciu, ponuka je sivá a povie prečo.
