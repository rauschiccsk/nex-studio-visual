# v4.81.0

**Keď sa stránka kokpitu pokazí, povie to — namiesto bielej obrazovky.** Ak sa niektorá stránka pri zobrazení zrúti,
kokpit ukáže vetu „Stránka narazila na chybu“ s tlačidlom „Obnoviť“; ľavé menu a horná lišta ostanú, takže sa dá
pokračovať inde. Chyba sa zároveň zapíše na server s tým, kde a pri akej verzii nastala, aby sa dala dohľadať a
opraviť. Doteraz takáto chyba nechala celé okno prázdne a nikto sa nedozvedel prečo.
