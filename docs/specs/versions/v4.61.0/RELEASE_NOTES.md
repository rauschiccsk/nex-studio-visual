# v4.61.0

**Kokpit už stavia projekty s webom a administráciou — voľba „Web“ je otvorená.** Nový projekt môžeš založiť ako Web
a existujúci štandardný projekt prepnúť na Web na jeho stránke v časti „Projekt s webom“ — kokpit najprv ukáže, čo
projekt dostane, a prepne ho až po potvrdení. Nasadenie dá webu hlavnú adresu inštalácie a administrácii adresu
s príponou „-admin“; obe sa pýtajú toho istého backendu. Po nasadení kokpit overí každú adresu a matica nasadení aj
návod na skúšku UAT ukazujú odkaz na administráciu aj na web. Štandardné inštalácie sa nemenia.
