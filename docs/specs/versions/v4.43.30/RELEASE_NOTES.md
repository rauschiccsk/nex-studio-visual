# v4.43.30

**Záložka UAT povie, čo otestovať.** Pod tabuľkou zákazníkov je panel „Čo otestovať vo verzii“. Pri každej zmene
ukáže obrazovku, kroky a čo sa má stať, a nad tým odkaz na UAT a e-mail, ktorým sa prihlásiš. Návod píše AI Agent
počas Programovania. Verifikácia skontroluje, že nechýba, a keď chýba, agent ho doplní, kým verzia prejde. Pri
starších verziách, ktoré návod nemajú, panel ukáže aspoň zmeny z ich poznámok k vydaniu.
