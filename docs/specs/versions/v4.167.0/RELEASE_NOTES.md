# v4.167.0

**Rýchla cesta s Poradcom: jedno tlačidlo schváli všetky otázky.** Poradca pri spoločnom posudku overí každú otázku
rovnako dôkladne ako pri „Overiť s Poradcom“ a ku každej pridá aj pokyn pre Staviteľa. Súhrn ukáže pri každej otázke
návrh Staviteľa, návrh Poradcu s dôvodom a jeho pokyn. Tlačidlo „Schváliť všetko“ schváli pri všetkých otázkach návrh
Poradcu, aj tam, kde Staviteľ navrhol inak, a Staviteľ dostane jeho voľbu spolu s pokynom. S otázkou, s ktorou
nesúhlasíš, klikni „Prekonzultovať“: vypadne zo spoločného schválenia, pod jej riadkom sa otvorí karta a rozoberieš ju
s Poradcom. Poradca pritom vloží svoj návrh priamo do tejto otázky. Tlačidlo „Posúdiť znova“ dá karty Poradcovi ešte
raz, napríklad súhrnu, ktorý vznikol pred touto verziou a pokyny ešte nemá.
