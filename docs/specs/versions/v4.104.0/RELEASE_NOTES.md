# v4.104.0

**Ostrý stroj zákazníka sa vyberá v kokpite.** Pri zákazníkovi (Zákazníci → upraviť) je voľba „Ostrý stroj (PROD)“
— ANDROS alebo MAGER. Kokpit podľa nej nasadzuje PROD tohto zákazníka a stránka PROD pri riadku zákazníka ukazuje, na
ktorý stroj. Zmena stroja nič nepresunie: inštalácia na pôvodnom stroji ostáva, kým ju niekto neodstráni.
