# v4.109.0

**„Uprav“ je v Riadiacom centre všade, kde ho kokpit ponúka.** Keď stavba čaká na teba a iné „Upraviť“ na obrazovke
nie je — pri pláne úloh pred programovaním, pri pozastavenej stavbe aj po jej prerušení —, pole rozhovoru má popri
„Poslať“ aj „Uprav“. „Poslať“ pošle AI Agentovi správu, „Uprav“ mu vráti prácu na úpravu podľa tvojho textu — pri
pláne úloh plán. Pokyn z Poradcu („Vložiť do Riadiaceho centra“) tak pri pláne úloh odošleš ako úpravu plánu; doteraz
odišiel ako otázka a agent ho prijať nemohol.
