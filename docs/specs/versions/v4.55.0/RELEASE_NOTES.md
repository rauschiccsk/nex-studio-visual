# v4.55.0

**Záložka Repozitár ukáže, kde bežia kontroly projektu, a chýbajúci vykonávač kontrol spustíš jedným klikom.** Doteraz
dostal vlastný vykonávač kontrol na ANDROSe len projekt, ktorý kokpit založil; prevzatý projekt ho nemal a jeho kontroly
bežali na platených strojoch GitHubu bez toho, aby to bolo kdekoľvek vidieť. Teraz záložka povie, či má projekt vlastný
vykonávač a či je prihlásený na GitHube; keď nemá, tlačidlo „Spustiť vykonávač kontrol“ ho spustí rovnako ako pri
založení projektu. Pod tým vymenuje každú úlohu CI, ktorá beží mimo neho — tie treba zmeniť v projekte samotnom.
