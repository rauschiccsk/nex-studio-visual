# v4.59.0

**Vo Vizuáli má každý frontend vlastný živý náhľad.** Web projekt ukáže dva náhľady — Administráciu aj Web — každý
s vlastným odkazom „Otvoriť: …“, a keď niektorý nebeží, kokpit povie, ktorý a prečo, a „Spustiť náhľad znova“ spustí
len ten. V zozname, čo skontrolovať, je pri obrazovke meno frontendu a odkaz vedie do jeho náhľadu. Schválený
Vizuál uloží obrazovky oboch frontendov a pri zmazaní projektu zmiznú oba náhľady. Štandardné projekty majú náhľad
bez zmeny.
