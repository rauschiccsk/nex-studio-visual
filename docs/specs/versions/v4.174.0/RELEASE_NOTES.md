# v4.174.0

**Podklad z internetu sa dá doplniť aj do založeného projektu.** Poradca projektu môže pod odpoveďou ponúknuť zoznam
podkladov, napríklad príručku banky, ktorá v projekte chýba, s tlačidlom „Stiahnuť do projektu“. Kokpit ich stiahne
rovnako bezpečne ako pri založení projektu, pridá ich k tomu, čo projekt má, a na stránke verzie ich ukáže v časti
„Podklady z internetu“. Čo už prišlo z tej istej adresy, znova nesťahuje.

**Verejný súbor sa uvedie, aj keď ho agent sám neprečíta.** Projektant aj Poradca dajú do zoznamu každý verejný
súbor, aj keď im ho web prečítať nedovolí — kokpit sťahuje ako prehliadač a súbor zvyčajne dostane. Sťahovanie už
neukladajú Manažérovi.

**Neúplný zoznam podkladov obrazovka neponúkne.** Odpoveď, v ktorej zoznam podkladov nie je úplný, nič neponúkne a
povie prečo — predtým to platilo len pre samotné založenie projektu.
