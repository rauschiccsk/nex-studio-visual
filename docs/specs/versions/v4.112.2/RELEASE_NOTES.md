# v4.112.2

**Upratovanie po nasadení je opäť jedno.** Verzia 4.111.0 pridala k doterajšiemu upratovaniu na serveri druhé, s iným
pravidlom pre staré verzie obrazov a s iným stropom pre medzipamäť stavieb; na serveri ANDROS by pri najbližšom nasadení
zmazalo medzipamäť, ktorú tam kokpit zámerne necháva. Druhé upratovanie je preč — staré verzie obrazov a medzipamäť
stavieb upratuje kokpit ako doteraz. Kontrola miesta pred nasadením a veta pri plnom disku ostávajú.
