# v4.76.1

**Požiadavky zo Zásobníka sa po dokončení verzie označia ako realizované.** Doteraz ostávala požiadavka zaradená do
verzie „zaradená“ aj potom, čo bola verzia hotová, a zoznam „Realizované“ bol prázdny. Označovala ju len stará cesta
vydania verzie z prvej verzie kokpitu, ktorú nič nevolalo. Teraz sa to stane pri každom dokončení stavby — po
Manažérovom „Hotovo“ aj po rýchlej oprave. Požiadavka realizovaná skôr si pôvodný dátum ponechá.
