# v4.118.0

**Každé konto má svoju farbu — viac kokpitov vedľa seba si nepomýliš.** Keď pustíš kokpit pod viacerými kontami naraz
(každé vo vlastnom profile Chrome), každé okno ukáže farbu svojho konta v tenkom pruhu hore a pri mene konta vpravo
v hornej lište. Meno konta je aj v názve okna, takže okná rozlíšiš aj na paneli úloh. Každé konto dostalo farbu samo;
zmeníš si ju v Nastaveniach → Moje konto → „Farba konta“.
