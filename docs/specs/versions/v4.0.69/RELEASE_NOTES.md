# v4.0.69 — NEX Studio Visual

## Bežný text je hrubší a lepšie čitateľný

Na tmavom podklade svetlý text opticky redne — je to známy jav a v tmavom režime sa preto hrúbka písma zvykne mierne dvíhať. Bežný text mal doteraz základnú hrúbku; teraz je o stupeň hrubší.

Nadpisy a zvýraznené údaje sa nemenia, takže hierarchia zostáva — nadpis je stále výraznejší než text pod ním.

Zmena nič nesťahuje navyše. Písmo Inter, ktoré aplikácia od predchádzajúcej verzie nesie so sebou, je **variabilné** — obsahuje plynulý rozsah hrúbok v jedinom súbore, takže medzihodnotu vieme použiť zadarmo.
