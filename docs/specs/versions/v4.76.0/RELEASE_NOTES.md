# v4.76.0

**Z databázy kokpitu zmizlo, čo nikto nečítal.** Na stránke verzie a v zozname verzií projektu už nie je číslo
„chyby“ — bolo vždy nula, lebo chyby sa riešia rýchlymi opravami a Zásobníkom, nie samostatným zoznamom chýb z prvej
verzie kokpitu. Spolu s ním je preč tabuľka chýb a šesť stĺpcov, ktoré nič nevypĺňalo ani nečítalo. Pred zmenou bola
urobená záloha databázy. Kontrola nepoužívaného kódu sa už nedá oklamať tým, že sa meno len uvedie v zozname
exportov.
