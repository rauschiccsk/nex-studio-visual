# v4.103.5

**„Nasadiť znova“ aplikáciu znova prepojí s NEX Managerom zákazníka.** Keď sa NEX Manager postaví nanovo a dostane
nové kľúče, aplikácie, ktoré sa z neho otvárajú, sa pri najbližšom nasadení prepoja: prevezmú jeho kľúč spustenia,
meno inštalácie a adresu, a keď ich NEX Manager už nemá zaregistrované, zaregistrujú sa v ňom znova. Ostatné
nastavenia inštalácie ostávajú. Upozornenie „Z NEX Managera sa nedá otvoriť“ radí, pri ktorej aplikácii stlačiť
„Nasadiť znova“.
