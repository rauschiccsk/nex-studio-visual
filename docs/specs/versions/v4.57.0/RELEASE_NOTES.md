# v4.57.0

**Web projekt dostane pri založení aj verejnú stránku.** Kokpit založí okrem administrácie aj web: prihlásenie
e-mailom a heslom, registráciu a odhlásenie. Web má vlastné automatické kontroly (CI) a kontrolu pred uložením rovnakú
ako administrácia. Výzva na povýšenie spoločného dizajnového kitu (nex-shared) ukáže verziu oboch frontendov a povýši
ich naraz. Projekt prepnutý na Web dostane ten istý web; keď sa web nedá pridať, projekt ostane, aký bol. Voľba „Web“
je zatiaľ zašednutá, kým kokpit nebude vedieť web ukázať vo Vizuáli, overiť aj nasadiť.
