# v4.133.1

**Po schválení Vizuálu už nechodí falošné „agent označil rozpor“.** Staviteľ po schválení Vizuálu zapíše dohodnuté do
Špecifikácie a Návrhu a rozpor, o ktorom musíš rozhodnúť ty, ohlási. Kokpit doteraz hľadal slovo „rozpor“ kdekoľvek
v jeho odpovedi, takže aj veta „Rozpor som nenašiel“ znamenala ohlásený rozpor: dostal si upozornenie „agent označil
rozpor a žiadny nevymenoval … prezri si Špecifikáciu a Návrh“, hoci rozpor nebol (od septembra 20-krát). Teraz je
rozpor len to, čo Staviteľ naozaj ohlási ako rozpor na rozhodnutie — dostaneš ho ako rozhodovaciu kartu ako doteraz.
