# v4.0.37 — NEX Studio Visual

## Oprava: zakladanie projektu (dokončenie)

Po doplnení nástroja git (v4.0.36) zakladanie projektu padalo o krok ďalej — pri prvom commite, lebo prostredie nemalo nastavenú identitu pre git. Doplnené: serverové prostredie má teraz identitu pre git a dôveruje priečinkom projektov, takže zakladanie projektu prejde celým procesom až po hotový projekt.
