# v4.141.1

**Podobné tikety sa nájdu, aj keď je slovo v inom tvare.** Hľadanie podobných tiketov — náhľad pod tlačidlom
„Založiť tiket“ aj nástroj, ktorým Poradca pozerá tikety kokpitu — porovnávalo celé slová, takže „šablóne“ sa
nestretlo so „šablóna“ a podobný tiket zostal skrytý. Teraz porovnáva základ slova bez slovenskej koncovky
(šablóna, šablóne, šablónach; projekt, projektov, projekty). Na podobnosť ďalej treba aspoň dve spoločné slová,
pri krátkom názve všetky.
