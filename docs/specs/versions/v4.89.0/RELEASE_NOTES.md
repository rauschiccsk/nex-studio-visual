# v4.89.0

**Stavba sa po zostavení plánu úloh zastaví — programovanie spustíš sám.** Doteraz kokpit v Programovaní zostavil
plán úloh a v tej istej sekunde začal prvú úlohu, takže veľkosť plánu a odhad, ako dlho bude agent pracovať, si
videl až počas programovania. Teraz stavba po zápise plánu čaká: v rozhovore uvidíš, koľko má plán epicov, featov
a úloh a odhad práce agenta, a v Pláne úloh tlačidlo „Spustiť programovanie“. Plán môžeš tlačidlom „Uprav“
s pripomienkou vrátiť agentovi na prepracovanie a na otázku k plánu ti agent odpovie bez toho, aby začal
programovať. Platí pre novú verziu pri každej Miere autonómie; rýchla oprava sa nemení.
