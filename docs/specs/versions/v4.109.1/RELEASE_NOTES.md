# v4.109.1

**Pokyn z Poradcu odíde hlavným tlačidlom ako „Uprav“.** Keď v poli Riadiaceho centra stojí pokyn vložený z Poradcu
a stavba „Uprav“ ponúka, hlavné modré tlačidlo aj kláves Enter je „Uprav“ a riadok nad poľom to povie; „Poslať“ ostane
vedľa. Platí, kým pokyn neodošleš alebo pole nevyprázdniš — aj keď ho medzitým upravíš alebo obnovíš stránku. Doteraz
bolo hlavné „Poslať“ a pokyn pri pláne úloh odišiel ako otázka. Vlastný text ostáva ako doteraz: Enter ho pošle ako
správu.
