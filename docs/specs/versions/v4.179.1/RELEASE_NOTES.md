# v4.179.1

**Neuložené zmeny uložíte priamo pri pridávaní webového frontendu.** Keď pridaniu webu bránia neuložené zmeny projektu
(napríklad rozpracovaný Vizuál), panel „Frontendy projektu“ ukáže, čo je neuložené, a tlačidlá Uložiť a Zahodiť —
rovnako ako pri zakladaní verzie. Po uložení sa formulár „Pridať webový frontend“ ukáže sám. Doteraz panel posielal na
stránku novej verzie a jeho veta ešte hovorila o „prepnutí“.
