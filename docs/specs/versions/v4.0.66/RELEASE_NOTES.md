# v4.0.66 — NEX Studio Visual

## Formátovaný text je čitateľný aj vo svetlom režime

Na obrazovkách **Prístupy** a **Znalostná báza** sa formátovaný text vykresľoval podľa tmavého režimu bez ohľadu na to, ktorý režim je zapnutý. Nadpisy a odstavce to nepocítili — tie majú farbu určenú zvlášť — ale odrážky, citácie a oddeľovacie čiary vo svetlom režime takmer splývali s pozadím.

Teraz sa tmavé formátovanie použije len v tmavom režime. V tmavom režime sa nemení nič.
