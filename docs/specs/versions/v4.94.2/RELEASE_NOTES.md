# v4.94.2

**Odpoveď Poradcu na otázku agenta vyzerá zase prehľadne.** Zelenou je len to, čo treba vybrať: voľba na karte alebo
krátka odpoveď agentovi, napríklad „Áno, súhlasím“, s tlačidlom „Vložiť do odpovede“. Dlhšia odpoveď pre agenta je
ako pokyn — samostatný blok „Odpoveď pre agenta“ a pod odpoveďou fialové tlačidlo „Vložiť do Riadiaceho centra“,
ktoré ju vloží do poľa odpovede agentovi. Doteraz sa dlhá odpoveď ukázala ako jeden veľký zelený rámik a fialové
tlačidlo chýbalo.
