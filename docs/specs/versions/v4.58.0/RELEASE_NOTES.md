# v4.58.0

**Agenti Web projektu vedia, že stavajú administráciu aj web.** Pravidlá agenta aj Audítora v projekte s webom opisujú
oba frontendy, dve skupiny používateľov s oddelenými účtami — zamestnancov, ktorí sa prihlasujú menom, a verejnosť,
ktorá sa prihlasuje e-mailom a registruje sama — a že prvý správca sa zakladá menom. Zadanie Vizuálu menuje oba
frontendy a Audítor porovnáva so schváleným Vizuálom oba. Štandardné projekty dostávajú pravidlá aj zadania
bez zmeny.
