# v4.74.1

**Otázka agenta prichádza k Poradcovi čitateľne.** Pri „Overiť s Poradcom“ na otázke agenta stojí v rozhovore najprv
jedna veta o tom, kde stavba stojí a na čo čaká, potom celá otázka agenta tak, ako ju napísal (s nadpismi a odsekmi),
potom čo agent pred otázkou napísal a nakoniec prosba. Doteraz sa nadpis otázky zlepil s prvým riadkom („Otázka
agenta — ## …“). Pri zmene databázy sa jej opis uvádza ako zmena, ktorú navrhuje stavba, nie ako slová agenta.
