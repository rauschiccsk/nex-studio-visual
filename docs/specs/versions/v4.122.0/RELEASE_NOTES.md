# v4.122.0

**„Vložiť do Riadiaceho centra“ z Poradcu prenesie aj voľbu, ktorú Poradca odporučil zelenou.** Karta rozhodnutia ju
má hneď vybranú a pod ňou stojí Poradcov pokyn — stačí skontrolovať a kliknúť „Rozhodnúť“. Prenesie sa len zelená
voľba (karta ju ponúka presne tak), len na kartu, ktorú Poradca menuje, a nikdy neprepíše voľbu, ktorú si na karte
vybral sám. Nič sa neodosiela samo.
