# v4.43.29

**Voľba, ktorú Poradca odporúča, je zelená.** Keď Poradca radí ku karte s otázkou agenta, voľbu, ktorú treba
vybrať, ukáže ako zelený štítok s číslom karty. Nad jeho odpoveďou je súhrn „Vyber“, takže ju nemusíš hľadať
v dlhom texte. Pri otázke agenta bez kariet je zelená odpoveď, ktorú Poradca odporúča („Odpovedz agentovi“).
Kokpit voľbu porovná s kartou. Keď ju karta v tomto znení neponúka, štítok je oranžový s upozornením „Takú možnosť
karta nemá — skontroluj kartu“. Platí pre nové rozhovory s Poradcom.
