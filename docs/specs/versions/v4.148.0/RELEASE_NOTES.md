# v4.148.0

**Aplikácie hovoria aj po anglicky a nový projekt začína so slovenčinou, maďarčinou a angličtinou.** Angličtina pribudla
medzi jazyky aplikácie — pri projekte, pri zákazníkovi aj v Nápadoch u Projektanta. Každý nový projekt so šablónou
NSV štandard má predvolene tri jazyky: slovenčinu ako hlavný jazyk, maďarčinu a angličtinu; inú kombináciu vyberieš
vo formulári. Existujúcim projektom sa jazyky nemenia — zmeníš ich v Nastaveniach projektu.

Angličtinu pozná šablóna aplikácie od verzie nex-app-kit 0.15.0. Keď projekt stojí na staršej, Nastavenia projektu
povedia, ktorú verziu jazyky potrebujú, a ponúknu jej povýšenie tlačidlom; to isté stráži Overenie verzie.
