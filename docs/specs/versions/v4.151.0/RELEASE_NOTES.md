# v4.151.0

**Staviteľ si dokumentáciu iného projektu prečíta sám.** Keď nová aplikácia stojí na inom projekte kokpitu — napríklad
číta vedomosti z NEX Knowledge —, Staviteľ má počas Prípravy, Návrhu, Vizuálu a Programovania k dispozícii
dokumentáciu ostatných projektov len na čítanie: ich README a dokumenty z priečinka docs. Kód, nastavenia, prílohy ani
iné súbory z nich nedostane. Manažér mu tak už nemusí sťahovať a prikladať dokumenty, ktoré kokpit má.

**Poradca projektu vidí ostatné projekty.** Poradca na projekte dostal tie isté nástroje ako Projektant v Nápadoch:
zoznam projektov kokpitu a dokumentáciu ktoréhokoľvek z nich. Keď sa Staviteľ pýta na dokument iného projektu, Poradca
ho prečíta a poradí odpoveď, namiesto toho, aby posielal Manažéra súbor ručne stiahnuť a priložiť.
