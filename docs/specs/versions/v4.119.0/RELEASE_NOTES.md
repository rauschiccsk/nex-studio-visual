# v4.119.0

**Jeden e-mail môže mať viac kont.** Kto má v kokpite viac kont (napríklad správcovské a pracovné), môže mať pri
každom svoj e-mail — pri zakladaní konta, pri úprave v Nastaveniach → Používatelia aj v Nastaveniach → Moje konto.
Prihlasuje sa ďalej menom, ktoré ostáva jedinečné: obsadené prihlasovacie meno kokpit odmietne ako doteraz.
