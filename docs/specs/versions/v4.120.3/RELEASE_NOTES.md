# v4.120.3

**Prevod staršieho projektu na šablónu aplikácie prejde.** Projekt založený pred opravou háčika pred zápisom (napríklad
NEX Websites) mal zastaraný háčik, ktorý pri prevode zastavil zápis do gitu. Prevod teraz zapíše spolu so šablónou aj
aktuálny háčik kokpitu. Keď prevod zlyhá, upratá po sebe aj to, čo pripravil na zápis, a nový pokus začne od čistého
stavu. V „Technický detail“ a v zázname kokpitu je vidieť, čo presne git odpovedal.
