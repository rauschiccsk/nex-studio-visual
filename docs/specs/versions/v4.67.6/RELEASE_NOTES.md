# v4.67.6

**Inštalácia projektu, ktorý sa medzitým prepol na Web, dostane pri ďalšom nasadení aj web.** Doteraz kokpit do
existujúcej inštalácie len nasadil novú verziu a na chýbajúci web iba upozornil. Verejný web tak nevznikol
a administrácia zostala na hlavnej adrese. Teraz do inštalácie pribudne web na hlavnej adrese a administrácia sa
presunie na adresu „-admin“, rovnako ako pri novej inštalácii. Dáta, heslá a ostatné služby inštalácie ostanú
nedotknuté. Inštaláciu s vlastným ručným smerovaním kokpit nezmení a v hlásení nasadenia povie, čo treba doplniť.
