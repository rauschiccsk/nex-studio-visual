# v4.169.0

**Rýchlu opravu, ktorá ešte nič neurobila, zrušíš tlačidlom.** Keď rýchla oprava vznikne omylom alebo s nesprávnym
zadaním, v Riadiacom centre je nad rozhovorom tlačidlo „Zrušiť rýchlu opravu“. Po potvrdení sa oprava zruší celá aj
s rozhovorom so Staviteľom. Ďalšia rýchla oprava projektu potom dostane jej číslo znova. Keď oprava vznikla z tiketu,
tiket sa v Plane vráti do Todo s komentárom. Zrušiť sa dá len oprava, ktorá je ešte v Príprave a na ktorej Staviteľ
práve nepracuje. Inak je tlačidlo zašednuté a pri ukázaní myšou povie dôvod.
