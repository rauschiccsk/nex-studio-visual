# v4.180.0

**Snímku obrazovky dáš Staviteľovi cez Ctrl+V alebo pretiahnutím.** V okne rozhovoru so Staviteľom aj v poli odpovede
vložíš snímku zo schránky (Ctrl+V) alebo do riadku pretiahneš súbor či obrázok — uloží sa rovnako ako cez „Priložiť
súbor“ (do projektu, mimo gitu) a do správy pribudne riadok, kde ju Staviteľ nájde. Snímka zo schránky dostane meno
s dátumom a časom, napríklad snimka-2026-11-27-1215.png. Vložený text sa vkladá ako doteraz. Poradca a Nápady to
vedeli už predtým.

**Povýšenie šablóny posunie aj web.** Webový projekt na šablóne aplikácií má administráciu aj web; tlačidlo „Povýšiť
šablónu“ doteraz posunulo len administráciu a server a web by ostal na starej verzii. Teraz povýši každý frontend
projektu, ktorý na šablóne stojí, v jednom kroku — a keď sa niektorý nepodarí, nezmení sa nič.
