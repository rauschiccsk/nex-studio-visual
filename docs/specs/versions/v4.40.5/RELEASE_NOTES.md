# v4.40.5

Pri zákazníkovi sa dá odteraz povedať, **na ktorom serveri beží jeho ostrá prevádzka**. Keď je to iný stroj než ten, kde beží kokpit, nasadenie tam pôjde samo — rovnakým kliknutím ako pri testovacej inštalácii, bez ručného prenášania.

Prázdne políčko znamená „tento stroj", takže pre zákazníkov, ktorí bežia tu, sa nemení nič. Testovacie inštalácie zostávajú vždy tu.
