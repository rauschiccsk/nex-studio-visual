# v4.0.48 — NEX Studio Visual

## Prepínač „Pri počítači" / „Preč" má teraz KAŽDÝ používateľ

V ľavom paneli dole je prepínač **🟢 Pri počítači / 🌙 Preč** — keď ho prepneš na „Preč", upozornenia na rozhodnutia ti chodia na Telegram aj s otvoreným Riadiacim centrom. Doteraz ho videl len správca.

Opravené:

- **Prepínač vidí a používa každý používateľ** — nie len správca. Odkedy si Junior vytvára a vedie **vlastné** projekty, potrebuje rovnaký signál: keď odíde od počítača a jeho projekt narazí na rozhodnutie, upozornenie mu príde na **jeho** Telegram.

(Systém to už vedel posielať správnemu človeku — chýbalo len tlačidlo v paneli. Teraz ho má každý.)
