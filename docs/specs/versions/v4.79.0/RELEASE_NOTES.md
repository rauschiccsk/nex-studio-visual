# v4.79.0

**AI Agent pozná pravidlá aplikácie pre viac zákazníkov.** Keď sa aplikácia opravuje podľa dokladu jedného zákazníka,
oprava ide ku všetkým — a nesmie pokaziť nikoho iného. Agent preto v každom projekte dostane tri pravidlá: doklad
dodávateľa číta spoločná aplikácia rovnako pre všetkých zákazníkov; čím sa zákazník líši, je nastavenie jeho
inštalácie s predvolenou hodnotou, ktorá nič nemení existujúcim zákazníkom; a každý skutočný doklad, na ktorom sa
niečo opravovalo, ostáva v skúškach projektu natrvalo — anonymizovaný, s očakávaným výsledkom. Audítor pri
Verifikácii overí, že sa pravidlá dodržali a zbierka dokladov sa doplnila.
