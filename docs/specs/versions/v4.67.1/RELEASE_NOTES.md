# v4.67.1

**Pravidlá Poradcu majú opäť zmysluplnú vetu o slangu.** Po hromadnej oprave slova v kokpite tam stálo, že namiesto
slova „aplikácia“ sa nemá písať „aplikácia“. Veta teraz znova uvádza slangový tvar, ktorému sa má Poradca vyhnúť. Kontrola
kokpitu odteraz upozorní na každú vetu, ktorá stavia slovo proti sebe samému, aby sa takéto pokazenie nezopakovalo.
