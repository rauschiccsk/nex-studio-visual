# v4.62.0

**Poradca posudzuje projekt podľa tých istých pravidiel ako agenti stavby.** Pri každej otázke vie, či je projekt
štandardný alebo Web, aké má frontendy, ako sa do nich prihlasuje a aké porty im kokpit pridelil. Poradca Web projektu
dostane pravidlá Web projektu, ktoré čítajú aj agenti stavby; keď sa projekt prepne na Web, otvorený rozhovor ich
dostane pri ďalšej otázke. Keď sa ho pýtaš, či schváliť výstup fázy, porovná ho so zadaním, s údajmi kokpitu aj s tým,
čo kokpit neskôr sám overí, a povie, s čím porovnával.
