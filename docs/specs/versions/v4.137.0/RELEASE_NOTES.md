**Dokumentácia projektov nemenuje ľudí, len roly.** Projektant, Poradca aj Staviteľ píšu v zadaní, Špecifikácii,
Návrhu, kontraktoch, README a poznámkach k vydaniu roly — Manažér, strana NEX Genesis, zákazník, vedenie zákazníka —
nie mená ľudí. Meno, ktoré v rozhovore povieš, Projektant do zadania prepíše rolou a Staviteľ dokument, ktorý
upravuje, mien zbaví. Audítor pri previerke Návrhu aj pri Overení berie meno človeka v dokumentácii verzie ako chybu;
mená si kokpit berie z kont svojich ľudí, takže stráži aj nového kolegu odo dňa, keď dostane konto.
