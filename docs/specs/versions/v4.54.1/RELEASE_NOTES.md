# v4.54.1

**Tlačidlo „Pridať verziu“ na stránke projektu ukazuje to isté číslo, aké verzia dostane pri založení.** Doteraz si ho
stránka počítala sama a vedela ponúknuť číslo, ktoré už je obsadené; teraz sa pýta kokpitu, ktorý číslo určuje na jednom
mieste. Keď sa číslo zistiť nedá, tlačidlo povie „Pridať ďalšiu verziu“.
