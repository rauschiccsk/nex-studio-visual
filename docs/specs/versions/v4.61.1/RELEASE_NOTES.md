# v4.61.1

**Projekt sa dá prepnúť na Web aj vtedy, keď má v priečinku neuložené zmeny inde.** Prepnutie zapisuje len web,
tabuľku frontendov v `CLAUDE.md`, kontroly webu a kontrolu pred uložením — čaká už len vtedy, keď sú neuložené zmeny
práve v nich, a vtedy ich vymenuje. Ostatné zmeny v priečinku nechá presne tak, ako boli. Časť „Projekt s webom“ to
povie vopred, takže už neponúkne prepnutie, ktoré by potom odmietla.
