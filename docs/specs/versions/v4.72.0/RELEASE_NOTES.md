# v4.72.0

**Stavba, ktorá na teba čaká, ti to pripomenie na Telegrame.** Keď stavba čaká na Manažéra dlhšie ako 2 dni (na
schválenie fázy, Špecifikácie alebo na odpoveď agentovi), kokpit pošle pripomienku: ktorý projekt a verzia, od kedy
čaká a čo treba, s odkazom do Riadiaceho centra — a potom znova po každých ďalších 2 dňoch, kým niekto nekoná.
Interval nastavíš v Nastaveniach („Pripomienka čakajúcej stavby“). Stavbu, ktorú si pozastavil sám, ani tú, ktorá
stojí na chybe kokpitu, nepripomína. Reštart kokpitu pripomienku nezopakuje.
