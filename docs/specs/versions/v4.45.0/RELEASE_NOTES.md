# v4.45.0

**Fakturácia má vlastnú záložku v ľavom paneli, hneď pod Nákladmi.** Doteraz bola treťou voľbou na stránke Náklady,
vedľa pohľadov Verzia a Kumulatívne. Teraz ju otvoríš priamo z ľavého panela a ukáže súpisy dodávky všetkých verzií
vybraného projektu: čo je vydané, čo treba vydať a s akou sumou. Súpis vydáš rovno odtiaľ. Na stránke Náklady ostali
pohľady Verzia a Kumulatívne. Bez vybraného projektu je Fakturácia zašednutá, rovnako ako Náklady.
