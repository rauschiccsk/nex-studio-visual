# v4.101.5

**Agent projektu na šablóne aplikácie vie, čo kontroluje kontrola rámu pred Overením.** Pokyny k šablóne menujú
všetko, na čo sa kontrola pýta: komponenty rámu, stránky rámu, cesty servera šablóny a to, že na mieste zostavenia
šablóny na serveri nezáleží. Agent tak nehádá a nepridáva nič navyše. Zoznamy v pokynoch sú stále tie isté, podľa ktorých
kontrola naozaj kontroluje.
