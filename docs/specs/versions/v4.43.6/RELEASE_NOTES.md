# v4.43.6

**Poradca vidí karty rozhodnutí.** Počas konzultácie vie, ktorá karta je na rade, aké možnosti na nej sú a čo
si už rozhodol. Poradí preto presne: „Na karte 3 vyber možnosť ‚…‘“ — doslova tým textom, ktorý vidíš na
karte, nie vlastnými slovami. Pokyn pre AI partnera napíše ku karte, ktorá je práve na rade.
