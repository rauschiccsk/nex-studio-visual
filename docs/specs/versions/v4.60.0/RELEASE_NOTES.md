# v4.60.0

**Overenie Web projektu skúša administráciu aj web.** Pri overení verzie kokpit spustí oba frontendy a spýta sa
každého, či odpovedá; keď web neodpovedá, povie to menom a verzia neprejde. Web projekt, ktorému v nastavení chýba
služba administrácie alebo webu, neprejde ešte pred zostavením — s vetou, ktorá ju menuje. Skúška pred vydaním dostane
zoznam oboch frontendov a agent v nej overí prihlásenie do každého jeho spôsobom. Štandardné projekty sa overujú
ako doteraz.
