# v4.84.3

**„Uložiť ich“ a „Zahodiť“ pri neuložených zmenách robia presne to, čo karta ukazuje.** Karta „Neuložené zmeny“
počíta len tvoju prácu v projekte, no uloženie doteraz zapísalo do gitu projektu aj pravidlá a zručnosti agentov,
ktoré kokpit spravuje sám, a zahodenie ich zmazalo. Teraz sa uloží alebo zahodí len to, čo na karte vidíš; súbory
kokpitu ostanú, ako ich kokpit zapísal.
