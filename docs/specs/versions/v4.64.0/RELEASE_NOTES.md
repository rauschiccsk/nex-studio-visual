# v4.64.0

**Agent stavby už nemá kľúč, ktorým by mohol na GitHube čokoľvek zmeniť.** Agent dostáva kľúč, ktorým GitHub len
číta — výsledky kontrol a obsah repozitárov —, a na GitHub všetko odosiela kokpit. Kľúč kokpitu, ktorý siaha na
všetky repozitáre konta, sa k agentovi už nedostane žiadnou cestou.
