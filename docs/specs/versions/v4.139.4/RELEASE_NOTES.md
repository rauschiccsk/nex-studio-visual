# v4.139.4

**Karta po Overení už netvrdí „inú príčinu“, keď je tá istá.** Keď Overenie zlyhá druhýkrát, kokpit porovná príčinu
s predošlým kolom a povie, či sa slučka pohla dopredu. Dočasný priečinok, ktorý má pri každom behu náhodné meno, mu
však z tej istej príčiny urobil dve rôzne — a karta napísala „Oproti minulému kolu je to INÁ príčina — tá predošlá je
vyriešená“, hoci stavba stála na tej istej veci. Náhodné meno dočasného priečinka sa pri porovnaní teraz vynechá;
čo za ním nasleduje (zákazník, projekt), príčiny ďalej rozlišuje.
