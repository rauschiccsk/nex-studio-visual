# v4.130.2

**Projektant a Poradca sa pýtajú tak, aby „Súhlasím“ bolo jednoznačné.** Otázku na svoje odporúčanie položia jednou
vetou bez chvosta „…, alebo …?“ — napríklad „Súhlasíš s týmto rozsahom 0.1.0?“ namiesto „Súhlasíš s týmto rozsahom
0.1.0, alebo chceš niečo pridať či ubrať?“. Kto chce niečo iné, napíše to sám. Doteraz pri odpovedi „Súhlasím“ nebolo
jasné, s čím človek súhlasil: v nápade „FINANČNÝ MODUL - MAGER“ malo taký chvost 5 z 8 otázok Projektanta.
