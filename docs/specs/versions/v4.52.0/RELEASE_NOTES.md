# v4.52.0

**Karty rozhodnutí jednej fázy sa posudzujú v jednom rozhovore s Poradcom.** Tlačidlo „Overiť s Poradcom“ doteraz pri
každej karte založilo nový rozhovor — pri deviatich kartách Návrhu deväť. Prvá karta fázy teraz založí rozhovor
s názvom napríklad „1.9.0 — rozhodnutia v Návrhu“ a každá ďalšia karta tej istej verzie a fázy doň pribudne ako
ďalšia otázka; Poradca tak pri ďalšej karte vidí aj svoje rady k predchádzajúcim. Keď ešte odpovedá na predchádzajúcu
kartu, otázka počká v poli, kým dokončí. Rozhovory, ktoré si napíšeš sám, zostávajú tak, ako boli.
