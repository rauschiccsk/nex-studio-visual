# v4.0.38 — NEX Studio Visual

## Oprava: zakladanie projektu (dokončenie toolchainu)

Zakladanie projektu potrebuje pri odoslaní na GitHub aj nástroj **GitHub CLI (gh)** — ten chýbal, takže krok „odoslať prvý commit na GitHub" zlyhal. Doplnené. Spolu s predošlými opravami (git + identita pre git) tak serverové prostredie má kompletný git/GitHub toolchain a **zakladanie projektu prejde celým procesom** až po hotový projekt na GitHube.
