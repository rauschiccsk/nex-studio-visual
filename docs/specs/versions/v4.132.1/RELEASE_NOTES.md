# v4.132.1

**Nápady ukazujú vždy ten nápad, ktorý je otvorený.** Keď si otvoril iný nápad skôr, než stránka dostala odpoveď
o predošlom, neskorá odpoveď ho prepísala: nadväzujúci nápad otvorený z „Nový nápad nadväzujúci na tento projekt“ sa
na chvíľu zamkol s vetou „Nápad skončil v projekte“ a „Opýtať sa“ zašedlo, pri rýchlom prepnutí v zozname sa mohol
ukázať predošlý nápad a „Pridať do projektu“ dokončené po prepnutí nahradilo otvorený nápad tým predošlým. Teraz stránka
odpoveď o nápade, ktorý už neukazuje, zahodí.
