# v4.105.0

**Nová ostrá inštalácia na inom stroji dostane meno a smerovanie toho stroja.** Zákazník s ostrým strojom MAGER
dostane inštaláciu s menom `<zákazník>-<aplikácia>.icc.sk` (dostupným cez Tailscale), na sieti a vstupnom bode Traefiku
MAGERa a s certifikátom, ktorý si MAGER vydá sám — tak, ako tam beží NEX Manager MÁGERSTAV. Odkaz na stránke PROD ukazuje
toto meno. Inštalácie na ANDROSe a prevzaté inštalácie s vlastným smerovaním sa nemenia.
