# v4.141.0

**Poradca pred návrhom tiketu kokpitu pozrie, či taký tiket už nie je.** Doteraz Poradca tikety kokpitu nevidel —
mohol tak navrhnúť tiket, ktorý už existuje, alebo pripomenúť prácu, ktorá je dávno hotová (13.11.2026 pripomenul
tiket štyridsať minút po tom, čo bol hotový a zavretý). Teraz má nástroj, ktorým nájde podobné tikety kokpitu,
otvorené aj uzavreté, a keď taký je, povie jeho číslo a stav namiesto nového návrhu. Hľadá tým istým spôsobom ako
náhľad pod tlačidlom „Založiť tiket“, ktorý ďalej ukazuje podobné otvorené tikety.
