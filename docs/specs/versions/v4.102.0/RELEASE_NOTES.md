# v4.102.0

**„Prejsť na overenie“ sa po Programovaní ponúkne až vtedy, keď prejdú kontroly na GitHube.** Kým bežia, tlačidlo je
zašednuté a pri ňom stojí, na čo sa čaká; keď prejdú, ponúkne sa samo. Keď kontroly zlyhajú, namiesto overenia sa
ponúkne „Vrátiť agentovi na opravu“ — agent dostane, čo zlyhalo, a oprava pobeží ako po tvojej úprave. Audítor tak
neoveruje verziu, o ktorej kokpit už vie, že jej kontroly neprešli.
