# v4.117.2

**Upratané mená v kóde kokpitu, na obrazovke sa nič nemení.** Súbory a priečinky kokpitu s opisným slovenským menom
majú anglické mená, ako zvyšok kódu (napríklad Riadiace centrum, Plán úloh, Repozitár, Špecifikácia). Poradca a Vizuál
ostávajú ako vlastné mená funkcií; texty a adresy stránok, ktoré vidíš, sú po slovensky ako doteraz.
