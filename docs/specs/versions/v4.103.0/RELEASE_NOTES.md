# v4.103.0

**Fakturácia počíta v kilotokenoch a sumy riadkov na desatiny eura.** Tokeny sa ukazujú v kT (1 kT = 1 000 tokenov),
zaokrúhlené hore na jedno desatinné miesto: 1 451 301 tokenov je 1 451,4 kT. Plná hodnota riadku súpisu je kT krát
sadzba, zaokrúhlená na desatiny eura od polovice nahor (1 451,4 kT × 2 € = 2 902,80 €), rovnako zľava; suma riadku je
ich rozdiel a „Spolu“ je súčet riadkov. Stĺpec s počtom riadkov kódu z Fakturácie aj z exportu CSV zmizol. Už vydané
súpisy si svoje sumy ponechajú.
