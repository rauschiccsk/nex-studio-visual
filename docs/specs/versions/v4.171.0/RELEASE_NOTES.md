# v4.171.0

**Stránka verzie ukáže zaradené tikety.** Na stránke verzie, ktorá sa ešte nezačala (Verzie → verzia), je nad
tlačidlom „Spustiť tvorbu špecifikácie“ zoznam tiketov zaradených do verzie s odkazom do Plane a tlačidlo „Zaradiť
tikety“. Staviteľ ich v Príprave dostane sám — čísla tiketov do zadania písať netreba.

**Zadanie povýšenia nevylučuje tikety.** Keď pri zakladaní verzie povýšiš knižnice rámu, kokpit už do zadania nepíše
„Žiadna iná zmena aplikácie do tejto verzie nepatrí“. Napíše, že tikety zaradené do verzie sú tiež jej súčasťou.
