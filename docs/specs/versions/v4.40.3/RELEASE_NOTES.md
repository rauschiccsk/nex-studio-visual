# v4.40.3

Keď nová verzia appky potrebuje nastavenie, ktoré nasadená inštalácia doteraz nemala, nasadenie jej ho **doplní** — a povie, ktoré to bolo. Doteraz sa to ticho preskočilo: appka síce bežala, ale bez toho nastavenia nefungovala celá, a zelené „Nasadené" to zakrylo. Presne tak sa stalo, že NEX Manager po nasadení nevedel povedať, akej je verzie.

Existujúce nastavenie inštalácie sa pritom **neprepíše nikdy** — dopĺňa sa len to, čo tam chýba.
