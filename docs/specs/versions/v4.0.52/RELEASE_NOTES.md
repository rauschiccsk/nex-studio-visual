# v4.0.52 — NEX Studio Visual

## „Poslať test" — over si, že Telegram upozornenia naozaj chodia

Doteraz, ak si mal zle nastavené Telegram chat ID (alebo si nespustil bota), upozornenia ticho nechodili a nedalo sa to zistiť. V **Nastavenia → Moje konto** je teraz pri Telegram poli:

- **Krátky návod:** napíš nášmu botovi `/start`, zisti svoje chat ID (napr. cez `@userinfobot`), vlož ho a ulož.
- **Tlačidlo „Poslať test":** pošle na tvoj Telegram testovaciu správu a **rovno ti povie výsledok** — buď „✅ odoslané", alebo presný dôvod, prečo nie (napr. „chat not found — spustil si bota?").

Neexpert si tak sám overí, že mu upozornenia budú chodiť — bez tichého zlyhania.
