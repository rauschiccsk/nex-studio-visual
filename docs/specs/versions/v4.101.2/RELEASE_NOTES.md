# v4.101.2

**Povýšenie šablóny aplikácie zoberie všetko, čo nová verzia potrebuje.** Keď pri zakladaní verzie povýšiš šablónu
(nex-app-kit), kokpit zdvihne aj nex-shared na verziu, s ktorou je nová šablóna overená, a doplní balíky, ktoré nová
šablóna pribrala. Predtým menil len samotnú šablónu a projekt by sa s novšou verziou nemusel zostaviť.
