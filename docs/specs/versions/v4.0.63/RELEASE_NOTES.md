# v4.0.63 — NEX Studio Visual

## Ľavý panel sa zmestí bez rolovania

Položiek v ľavom paneli pribudlo natoľko, že sa prestali zmestiť — spodok ponuky zmizol za rolovacou lištou a na „Aktualizácie" bolo treba rolovať.

Riadky sú teraz o niečo nižšie a celá ponuka sa zmestí naraz. Zmena je v spoločnej výbave, ktorú používajú všetky naše aplikácie, takže rovnaký problém už v žiadnej z nich nevznikne — každá si ju prevezme, keď na ňu príde rad.
