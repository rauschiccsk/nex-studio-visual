# v4.177.0

**Každý formulár v novej aplikácii ukladá rovnako.** Staviteľ dáva pod každý formulár tlačidlá Zrušiť a Uložiť, ktoré
sú aktívne len vtedy, keď sa vo formulári niečo zmenilo; Zrušiť zahodí zmeny. Pri tlačidle sa už nepíše „Uložené“ —
uloženie ohlási „✓ Uložené“ zelenou vpravo hore a samo zmizne. Knižnica nex-shared to od verzie 0.42.0 nesie sama;
aplikácia, ktorá už beží, to dostane vo svojej ďalšej verzii s novou knižnicou.
