# v4.95.0

**Orientačná cena verzie je vo Fakturácii.** Pri každej verzii s plánom úloh stojí pod sumou súpisu samostatný údaj
„Orientačná cena“: suma s rozptylom, z koľkých úloh a z koľkých hotových verzií odhad vychádza, rozpis na kód so
skúškami a dokumentáciu a upozornenie, keď sa odhad opiera o málo verzií. Pri hotovej verzii tak vidno vedľa seba
odhad aj skutočnú sumu súpisu. Doteraz sa cena počítala až pri otvorení stránky verzie, takže vo Fakturácii chýbala
pri každej verzii, ktorej stránku nikto neotvoril. Stránka verzie panel s orientačnou cenou už nemá.
