# v4.175.0

**Projektant schvaľuje zadanie po častiach.** V Nápadoch už Projektant neukáže celé zadanie naraz. Prejde ho s vami
postupne: jednu časť (Prečo, potom A, B, C …), počká, kým ju schválite alebo s ňou niečo prekonzultujete, a až potom
ukáže ďalšiu — nikdy dve časti naraz. Celé zadanie s tlačidlom „Založiť projekt“ ukáže, až keď sú schválené všetky
časti.

**Šípka späť a tesné riadky v každej novej aplikácii.** Staviteľ stavia každú obrazovku so šípkou „← názov
predchádzajúcej obrazovky“, ktorá vráti aj s filtrom a záložkou, a tabuľky s čo najnižšími riadkami. Šablóna
aplikácií nex-app-kit to od verzie 0.20.0 nesie sama (KitPage, KitTable, KitFields), takže to Manažér nemusí
vypytovať vo Vizuáli.
