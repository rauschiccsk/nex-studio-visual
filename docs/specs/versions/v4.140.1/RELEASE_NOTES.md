# v4.140.1

**Keď sa ťah agenta nečakane zrúti, kokpit ti to povie po slovensky a poradí, čo stlačiť.** Doteraz sa v takom
prípade v rozhovore objavila anglická správa „Agent dispatch failed … — pipeline blocked.“ aj s technickým výpisom
chyby. Teraz správa povie, že sa ťah agenta zrútil a stavba stojí, a že môžeš napísať, čo má agent urobiť inak, a
stlačiť „Skús znova“; technický dôvod je nižšie v technickom detaile. Nová kontrola stráži, aby kokpit v rozhovore
ani vo vete o stave stavby nepísal po anglicky.
