# v4.107.3

**NEX Manager sa dá previesť na šablónu aplikácie.** Návrh, ako NEX Manager prevezme dizajn šablóny a ostane tým, kto
prihlasuje ľudí do ostatných aplikácií, je schválený: karta „Previesť na šablónu aplikácie“ ho už neodmieta. Verzia
prevodu dostane v Príprave položku „Prenos dát do rámu šablóny“ ako každý projekt, ktorý beží u zákazníka.
