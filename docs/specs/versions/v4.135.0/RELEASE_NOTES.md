# v4.135.0

**Celá aplikácia sa navrhne na začiatku a prvá verzia ju celú postaví.** Projektant v Nápadoch už nerozdeľuje nový
projekt na „najmenší celok“ a ďalšie verzie. Zadanie opíše celý produkt — jeho účel, prehľad, všetky organické časti
(evidencie, obrazovky, rozhrania na iné systémy) a dátový model celku — a prvá verzia ho celý navrhne aj postaví. Časť,
ktorá závisí od iného systému, postaví celú na svojej strane. Ďalšie verzie sú len na neskoršie zmeny.

Staviteľ v Príprave navrhuje Špecifikáciu, dátový model aj obrazovky pre celý produkt a nič zo zadania sám neodloží
do „Mimo rozsahu“; to smie len Manažér. Audítor pri previerke Návrhu berie časť zadania, ktorú Staviteľ odložil sám,
ako medzeru.
