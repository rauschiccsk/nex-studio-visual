# v4.136.1

**Staviteľ vie, že aplikácia môže skryť aj položku Prehľad.** Šablóna aplikácií od verzie 0.12.0 dovolí skryť položku
Prehľad v ľavom paneli pred ľuďmi, ktorí ju nemajú vidieť — napríklad pred Operátorom v NEX Finance. Kto Prehľad
nevidí, začína na prvej položke aplikácie, ktorú vidí. Zručnosť šablóny, podľa ktorej Staviteľ stavia, to teraz
opisuje spolu so skrývaním ostatných položiek.
