# v4.120.2

**Pridelený port projektu sa nedá vyprázdniť — a kokpit to povie.** Keď v nastaveniach projektu vymažeš pridelený
port, pod poľom sa ukáže, prečo ostáva (kokpit ho drží v evidencii portov, aby ho nedostal iný projekt, kým na ňom
beží inštalácia), a „Uložiť“ počká, kým tam nie je číslo. Doteraz uloženie hlásilo úspech a port potichu ostal.
Zmeniť port na iné číslo môžeš ako doteraz.
