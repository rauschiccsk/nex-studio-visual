# v4.101.4

**Dátum verzie v Aktualizáciách aplikácie na šablóne je deň, keď bola verzia prvý raz overená alebo označená ako
hotová.** Zapíše sa aj vtedy, keď si poznámky k vydaniu napísal agent sám, a dátum zapísaný vopred počas stavby
nahradí. Neskoršie opätovné overenie ho nemení. Agent v pokynoch k šablóne číta, že tento dátum zapisuje kokpit.
