# v4.40.26

Pri rýchlej oprave dostane kontrolór zoznam vecí, ktoré má overiť — rovnaký, aký dostáva pri riadnej
verzii. Doteraz mal posúdiť, či sú dôležité vlastnosti aplikácie ošetrené, ale ten zoznam nevidel.

Kontrola pri rýchlej oprave zostáva ľahká, ako bola. Mení sa len to, že kontrolór vie, čo hľadá.
