# v4.100.0

**Nový projekt môžeš založiť na šablóne aplikácie „NSV štandard“.** Vo formulári nového projektu vyberieš šablónu
(predvolená je NSV štandard) a zaškrtneš, či aplikácia používa AI agentov. Projekt má potom od prvej verzie hotový
ľavý panel s Prehľadom, Ako začať, Aktualizáciami a Nastaveniami, prihlásenie aj server — agent stavia len obrazovky
aplikácie a kokpit pred Overením skontroluje, že rám ostal celý.

Keď vyjde novšia šablóna, pri zakladaní verzie ti kokpit ponúkne jej povýšenie, tak ako pri nex-shared. Projekty bez
šablóny sa nemenia.
