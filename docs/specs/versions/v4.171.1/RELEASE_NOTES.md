# v4.171.1

**Prostredie inštalácie pozná každá jej služba, ktorá si ho pýta.** Kokpit pri nasadení povie inštalácii, či je
testovacia alebo ostrá, komu slúži a v akom jazyku začína. Doteraz to povedal len backendu. Pracovník NEX HelpDesk
si prostredie pýta tiež — nedostal ho, jeho úlohy padali a hovory by nespracoval. Teraz údaj dostane každá služba,
ktorá ho má vo svojom nastavení; služba, ktorá si ho nepýta, ostane bez zmeny.
